## 2024-03-24 - Accessibility on flip-card elements
**Learning:** Adding `tabIndex={0}` and `role="button"` to a complex custom flip-card component makes it discoverable by screen readers and keyboards, but a clear `focus-visible` ring is necessary so sighted users navigating via keyboard can easily identify when the component is focused. Custom `div` interactions also require explicit `onKeyDown` handlers catching `Enter` or `Space` to replicate standard `button` behaviors. Additionally, scrolling defaults for `Space` need to be prevented using `e.preventDefault()`.
**Action:** When implementing custom interactive 3D/flip cards using generic `div`s, always include comprehensive keyboard handlers (Enter/Space) and visible focus indicators (`focus-visible:ring-4`) to ensure complete accessibility without compromising the custom animation.
