## 2026-05-05 - Added Keyboard Accessibility to Custom UI Elements\n**Learning:** Users who rely on keyboard navigation could not interact with the `CouponCard` because it was implemented using a generic `div` without keyboard event handlers or focus indicators. Visual buttons also lacked clear focus states.\n**Action:** Always verify that interactive custom components have `role="button"`, `tabIndex={0}`, `onKeyDown` support for 'Enter'/'Space', and distinct visual `focus-visible` states to ensure complete accessibility.
