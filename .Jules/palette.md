## 2024-05-18 - Interactive Div Accessibility
**Learning:** Generic `div` elements used as interactive components (like cards acting as buttons) often lack critical keyboard accessibility and screen reader support, creating a significant barrier for users who rely on non-pointer input devices. In this specific app's context, the `CouponCard` elements were missing essential ARIA attributes, semantic roles, and keyboard event handlers.
**Action:** When building interactive custom elements that function as buttons but aren't semantically `<button>` tags, always ensure to explicitly assign `role="button"`, provide keyboard focus via `tabIndex={0}`, communicate state with ARIA attributes like `aria-expanded`, and crucially implement `onKeyDown` handlers for the 'Enter' and 'Space' keys (including `e.preventDefault()` to stop spacebar page scrolling) alongside visual focus indicators such as `focus-visible:ring`.
